Lecture Search Method Replays

Each replay shows one search method planning on the same easy platformer level (seed 6), followed by a simple controller executing the planned route.

Breadth-first search (BFS)
Finds a route with the fewest abstract platform transitions. Uniform-cost search (UCS)
Prioritizes accumulated estimated jump distance, height change, and landing risk. Greedy best-first search
Prioritizes estimated remaining horizontal distance to the goal. A*
Combines accumulated route cost with the remaining-distance heuristic.
How to interpret these: The graph uses platforms as nodes and estimated feasible jumps as edges. All four methods complete this episode in 96 steps and collect all 9 gems. They choose the same route because this particular graph has only one route. The replays illustrate the methods and abstraction; they are not a benchmark, and they do not establish which method performs best.
